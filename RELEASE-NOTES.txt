Study Tool 1.3.0

GitHub Releases can now be used directly as the HTTPS update source. The app accepts a public repository or its Releases page, reads the latest published stable release, and chooses the Apple Silicon or Intel download for this installation. Checks reject incomplete downloads, missing SHA-256 digests, unexpected hosts, preview releases and invalid versions.

GitHub Actions workflows test source pushes and build both Mac editions for version updates pushed to main, matching version tags, or manual releases. Publication waits until GitHub confirms both archive sizes and hashes. Each release-built app receives its repository's update address automatically.

Unsigned releases are offered as manual downloads. With the account owner's Apple Developer ID signing and notarization secrets configured, the workflow can publish signed builds for Electron's native updater. Install this GitHub-aware edition, and the first Developer ID signed edition, manually once.

Manual downloads now also wait for pending saves and create an independent retained workspace checkpoint. Native downloads and restarts keep the existing backup safeguards.

The local workspace folder and format remain unchanged. All lattice, lasso, connection styles, corollary proofs, shared LaTeX settings, saved topics and backups from 1.2.0 remain supported. The updater never uploads study data.
