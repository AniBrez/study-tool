Study Tool 1.4.0

Section titles now open an assumptions card in Display. Add optional shared hypotheses for the definitions, theorems, lemmas, corollaries and remarks under a title, using the same text, LaTeX, lists and compiled preview as other cards.

In Edit, click an existing title or add a new Title, enter its assumptions and save. In Display, click the title to read them or choose Edit assumptions. Titles without assumptions remain supported. Title boxes keep the original canvas design and dimensions.

Assumptions persist in the existing workspace format and survive reopening, JSON export/import, undo and redo. Canceling an edit preserves saved assumptions. Unsaved title drafts receive the desktop close protection used by other cards.

All 73 automated checks pass locally, including title assumptions, desktop file saving, reloading, compatibility, storage recovery and updater safeguards.
